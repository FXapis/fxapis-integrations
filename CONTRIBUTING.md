# Contributing

See the [Contributing section](README.md#contributing) in the README for what each kind of
change needs before a pull request.

## Reporting a problem

[Open an issue](https://github.com/FXapis/fxapis-integrations/issues) with which template, what
you expected, and what happened. For an API or account issue rather than one with these
templates, email [support@fxapis.com](mailto:support@fxapis.com).
